# 会话卡模板

由入口在当前明确授权的合成操作中保存为 `runs/<run_id>/session-card.md`；初次菜单和只读“查看进度”不创建。当前文件是模板，不是已发生业务状态。

| 项目 | 值 |
| --- | --- |
| mode | SYNTHETIC_ONLY |
| run_id／batch_id／paper_id | 未选定 |
| student_ref／attempt_id | 未选定 |
| 当前操作 | 未开始 |
| 当前草稿／内容版本 | 无 |
| 原材料引用 | 仅用户明确点名的路径，未选定 |
| review_status | 未开始，后续使用共用规则状态 |
| archive_status | NOT_REQUESTED |
| release_status | NOT_PREPARED |
| 本次人工确认范围及来源引用 | 未收到；不复制示例当确认 |
| 输出与回读证据链接 | 无 |
| 正在等待什么 | 用户选择操作 |
| 下一步 | 未确定；“继续”不等于批准 |
| 更新依据与时间 | 只能填实际发生的信息 |

已有卡片更新前保留必要历史附录；不能修改确认事件来迎合卡片。卡片记录“当前视图采用R02、R01历史保留”，不写“R02覆盖并删除R01”。原卷快照与复测对象分别标记，跨批次切换须重置对象和版本，不能带入上一生的确认范围。

写卡时不存真实姓名、对应表、完整档案、API Key 或长对话。卡片丢失只影响接续便利，不允许靠猜测重建批准记录。卡片不提供事务、权限或崩溃恢复保证。
