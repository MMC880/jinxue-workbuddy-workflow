# 02 每生整卷分析

遵守 [工作流规则](../rules/WORKFLOW_RULES.md)和[数据边界](../rules/DATA_BOUNDARIES.md)。输入：已核对的当前批次、选定一名学生的整卷作答、对应原卷／参考答案、允许的 run 目录。输出使用 [整卷审核表](../templates/PAPER_REVIEW.md)。

1. 按整卷题序逐题对照，保留学生原答案／步骤，不按“本来应该写什么”替换它。看不清则给出需确认的具体符号，不直接判错。
2. 独立核对参考答案及条件。仅用可信表达式做数学工具核验；不要把 OCR 文本喂给可执行字符串解析器。工具不存在就如实注明，给推导并等待教师审查。
3. 每题给来源、原作答、AI 初判、依据、具体疑点／疑似错因、知识点／题型候选。区分计算错误、概念／方法／审题等证据不足的假设，不做心理标签。
4. 对缺页用 MISSING，不清用 PENDING，参考答案冲突用 PENDING 并列理由。不给未经约定的步骤分或掌握概率。
5. 生成当前生整卷草稿，review_status=WAITING_TEACHER；指出哪些内容需要确认，再调用 03 的人工复核步骤。

只可写当前生 review-<student>.md 草稿到指定合成 run。不能归档、发布、代教师勾选或自动开始下一生。做完整份才做该生小结；不跨十人集中审某题。
