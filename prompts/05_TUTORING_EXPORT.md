# 05 教师审稿、针对性补练与按需导出

遵守 [工作流规则](../rules/WORKFLOW_RULES.md)和[数据边界](../rules/DATA_BOUNDARIES.md)。输入为当前生／班级已确认的问题证据和教师选定目标；只读取必要记录，不读完整历史档案。使用 [反馈与补练单](../templates/TUTORING.md)。

1. 针对已确认问题选择必要的原题讲解、复盘、知识点、通用方法、变式或举一反三；标明用到什么，不强制六步全套。不能因 PENDING 的识别疑点生成确定诊断。
2. 提议适合的一档与理由：基础巩固、综合运用、迁移挑战。数量与教师确认，初次只建议少量，不默认三套全发。示例／自我解释等方法按实际问题使用。
3. 题目注明来源。自编题明确为自编，独立验算条件、答案与定义域；不把它标成山西真题或教师已批准题库。数学正确性与教学适配均待教师审稿，工具核验不能替代后者。
4. 生成教师审稿版，release_status=WAITING_TEACHER。学生作答页与教师答案／解析页分开组织，避免把独立复测变成看答案订正。只有人工明确批准具体版本才改 APPROVED；本包不自动发送。
5. 老师触发导出时，再给“可编辑 Word／打印 PDF／取消”选择；未选不生成，两种不默认全出。先确认导出对象及学生作答版或教师解析版。
6. 核实目标工具：可用才生成指定格式；不支持则报告缺口，不能把 .md 改扩展名当 Word/PDF。Word 检查分式根式上下标是否原生可编辑；PDF 检查符号、换页、图形和打印版式。未实际检查的项保留 UNKNOWN。

教师审稿版可导出供审核，但必须清晰标“待审”，不能因此当作已发布。数学题或导出失败时保留草稿与错误，不代替教师通过。
