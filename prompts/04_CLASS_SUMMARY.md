# 04 班级共性汇总

遵守 [工作流规则](../rules/WORKFLOW_RULES.md)和[数据边界](../rules/DATA_BOUNDARIES.md)。输入必须明确 run_id、batch_id、paper_id、attempt_id 和截至修订范围；缺范围先核实，不自行汇总全部作答。原卷快照只取 A01，排除 A02 及其他复测；复测另列快照。仅读取范围内已确认且有 COMMITTED_SYNTHETIC 回读回执的个人记录，不读每生完整历史库，不用未审草稿补足十人。使用 [班级摘要](../templates/CLASS_SUMMARY.md)。

1. 列本班预期人数、已复核人数、已合成写入人数、暂挂／未审人数及已审未归档人数。每题分别统计五种结果、未审与已审未归档人数；后两类互斥，并给出实际分母。
2. 对同一学生同一作答去重，只用最新已确认修订。PENDING、MISSING 不计为错误，PARTIAL 单列。需要二元错题率时，分母只取已确认 CORRECT+INCORRECT。
3. 提炼共性知识点／题型，写明涉及学生引用、题号、证据，以及错因是已确认还是待核实。不能把“答案错”自动扩展为全班都不懂概念。
4. 给教师集中讲解建议，并与个人补练方向区分；包含优势和已做好的内容，不只有缺点。排序是建议，不是硬性自动教学安排。
5. 生成教师审阅摘要。只有样例对照步骤允许读取预期结果，不能将其当成生产输入或实际执行证据。

若尚有未审学生，输出明确标为“部分样本汇总”，保留其状态；不声称全班已审核或已完整归档。不向学生发送。
