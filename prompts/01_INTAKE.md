# 01 收件核对

遵守 [工作流规则](../rules/WORKFLOW_RULES.md)和[数据边界](../rules/DATA_BOUNDARIES.md)，使用 [材料表](../templates/INTAKE.md)。仅当人工指定合成 run_id 与输入文件后执行；未指定时指出所缺信息。

1. 区分原卷、教师参考答案、学生作答；记录 batch/paper/student、页序、题号和来源，不读取答案去填补缺失学生作答。
2. 阅读指定材料并检查是否虚构。学生归属不明则整份暂挂；缺页、不清和参考答案疑点分别标记，不猜测学生或补写作答。
3. 形成十人收件清单，按学生列出完整／缺页／待补／未交；同一来源重复出现提示重复，先不要重复建档。
4. 输出拟处理顺序和需教师确认的疑点。仅在当前已授权 run 目录写 intake.md；没有写权限则在对话返回，不称已保存。

本步骤不判错、不生成长期薄弱结论。结束等待选定第一名学生或解决身份疑点；不得转成全班同题批阅。样例识别标记只是文本演练，不标记 OCR 已通过。
